# Firebase setup (project owner managed)

Create and configure the Firebase project yourself.

Planned integrations:
- Firebase Authentication
- Cloud Firestore
- Firestore security rules

Do not commit service-account JSON files or private credentials.

Before connecting the frontend, add the Firebase web app configuration to a local, untracked configuration file. Review Firestore rules before enabling user data access. Public Firebase web config is not a substitute for database security rules.

No Firebase project ID, API key, service account or credentials are included in this repository yet.
